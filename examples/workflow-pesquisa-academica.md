# Exemplo Real de Workflow: Pesquisa Acadêmica / Estado da Arte

**Objetivo:** Fazer uma revisão rápida e de qualidade sobre um tema técnico ou científico.

---

## Workflow Completo

### Etapa 1: Definição Clara do Escopo

**Prompt usado:**

```markdown
Quero fazer uma revisão do estado da arte sobre [TEMA].

Antes de começar, me ajude a refinar o escopo respondendo:
1. Quais são os principais sub-tópicos relacionados?
2. Qual período de tempo faz mais sentido cobrir?
3. Quais termos de busca você recomendaria usar?
```

### Etapa 2: Pesquisa e Coleta de Fontes

**Prompt usado:**

```markdown
Usando os termos de busca que definimos, faça uma pesquisa e liste as 8-12 fontes mais relevantes e confiáveis sobre o tema.

Para cada fonte, inclua:
- Título
- Ano
- Principais contribuições
- Link (se disponível)
```

### Etapa 3: Síntese Estruturada (usando o template Academic Research)

**Prompt usado:**

```markdown
[COLE AQUI O TEMPLATE DE ACADEMIC RESEARCH]

Tema: [TEMA]

Estrutura sugerida:
- Resumo executivo
- Contexto e motivação
- Principais abordagens atuais
- Avanços recentes (últimos 3 anos)
- Lacunas identificadas na literatura
- Direções futuras de pesquisa
- Conclusão

Use tabelas para comparar abordagens principais.
```

### Etapa 4: Análise Crítica (opcional, mas poderosa)

**Prompt usado:**

```markdown
Com base na revisão anterior, faça uma análise crítica respondendo:

1. Quais são os pontos de consenso na área?
2. Quais são os principais debates ou controvérsias?
3. Quais lacunas ainda não foram bem exploradas?
4. Se você fosse pesquisar esse tema hoje, qual abordagem você escolheria e por quê?
```

---

## Resultado Típico

Esse workflow costuma gerar:
- Uma revisão bem estruturada e citada
- Boa visão geral do tema em 15-25 minutos
- Identificação clara de lacunas de pesquisa
- Base sólida para escrever artigos, TCCs ou propostas de projeto
