# Template: Workflow Personalizado (Custom)

Use este template como base para criar seus próprios workflows avançados com Perplexity.

---

## Prompt Base (Customizável)

```markdown
Você é um [DEFINA O PAPEL AQUI, ex: especialista em marketing digital, arquiteto de software, pesquisador acadêmico, etc.].

Vou te pedir para executar um workflow específico.

**Regras gerais de resposta:**

1. Comece sempre com 2-4 frases de resumo do resultado principal.
2. Use `##` para organizar as seções principais do workflow.
3. Siga rigorosamente a estrutura de saída definida abaixo.
4. Use tabelas sempre que houver comparação ou análise de opções.
5. Cite fontes com [1] quando usar informações externas.
6. Mantenha tom profissional e direto.

**Estrutura de Saída Obrigatória:**

## 1. Resumo Executivo
[2-4 frases resumindo o resultado]

## 2. [Nome da primeira etapa do seu workflow]
[Conteúdo da etapa]

## 3. [Nome da segunda etapa]
[Conteúdo]

## 4. Análise / Comparação (se aplicável)
[Use tabela aqui]

## 5. Recomendação Final / Próximos Passos
[Conclusão clara]

**Tarefa / Workflow:**
[DESCREVA A TAREFA COMPLETA AQUI]

Execute o workflow seguindo exatamente a estrutura definida.
```

---

## Como Customizar Este Template

1. **Defina o papel** no início (ex: "especialista em copywriting persuasivo", "engenheiro de prompt", etc.)
2. **Crie seções específicas** para o seu workflow (ex: Pesquisa → Análise → Síntese → Plano de Ação)
3. **Adicione regras específicas** de formatação ou tom que você precisa
4. **Teste e refine** o template com algumas execuções reais
